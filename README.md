# Vantyi & Sons Funeral Parlour Website

A responsive multi-page HTML, CSS and JavaScript website project based on the supplied website proposal.

## Pages
- `index.html` — Home
- `about.html` — About Us
- `services.html` — Services
- `policies.html` — Funeral Policies
- `testimonials.html` — Testimonials
- `contact.html` — Contact Us
- `enquiry.html` — Enquiry form

## Run locally
Open the folder in Visual Studio Code. Install the Live Server extension, then right-click `index.html` and select **Open with Live Server**. You can also open `index.html` directly in a browser.

## Before publishing
The supplied proposal did not provide a verified phone number, email address, street address, office hours, approved logo, policy terms, or real customer testimonials. These have not been invented. Add verified business information and approved images before publishing.

The enquiry form is front-end demonstration only. It validates the fields and displays a message, but does not send or store enquiries. Connect it to a secure form backend or approved business email service before using it with customers. Do not collect sensitive personal or financial information through an unsecured form.

## GitHub submission
Create a **Public** GitHub repository. In VS Code, open Terminal > New Terminal and run:

```bash
git init
git add .
git commit -m "Create Vantyi and Sons website"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/vantyi-and-sons-website.git
git push -u origin main
```

Replace `YOUR-USERNAME` with your actual GitHub username. If the repository already contains a README or other files, follow GitHub's instructions to avoid overwriting existing work.
